# transactions 页面详情

## 页面列表
| 页面名 | 路由 | 说明 |
|--------|------|------|
| 交易管理页 | /transactions | 交易筛选、列表与 CRUD |

## 页面详情
- **路由**：`/transactions`
- **说明**：提供筛选区、分页列表、批量入账按钮和交易编辑弹窗
- **权限**：所有已登录用户

**页面结构**
- 桌面端：顶部筛选区 + 交易表格 + 批量操作区 + 统一分页器 + 新增/编辑弹窗。
- 移动端：可折叠筛选区 + 交易卡片列表 + 当前页选择器 + 固定批量操作栏 + 紧凑分页 + 可滚动弹窗。

**核心交互**
- 筛选区中的经手人使用用户下拉选择，展示名优先显示全名，缺失时回退登录名。
- 列表支持全选当前页记录。
- 列表展示 `summary` 主列，并在同一区域按需预览详情备注或前几条明细项。
- 新增/编辑弹窗中使用“摘要 + 详情备注 + 明细项列表”的结构化编辑方式维护交易内容。
- `transaction_type` 与 `entry_status` 以不同颜色标签展示不同语义状态。
- 移动端筛选器默认折叠并显示已启用筛选数量；重置筛选后回到第 1 页。
- 每张移动卡片展示摘要、类型、状态、金额、日期、分类和经手人，并保留选择、编辑和删除能力。
- 新增/编辑弹窗在动态视口内滚动，详情项和底部操作在 320px 视口下仍可访问。
