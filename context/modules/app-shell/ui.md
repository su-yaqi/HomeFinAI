## 页面详情

### 应用主框架
- **路由**：`/_layout/*`
- **说明**：为所有受保护页面提供统一侧边栏、顶部栏、内容容器与页脚
- **权限**：所有已登录用户

**页面结构**
- 桌面端：左侧常驻侧边栏 + 顶部栏 + 主内容区 + Footer。
- 移动端：顶部菜单触发器 + 抽屉侧边栏 + 单列主内容区 + 安全区 Footer。

**核心交互**
| 操作 | 触发方式 | 行为描述 |
|------|---------|---------|
| 导航跳转 | 点击侧边栏菜单 | 跳转目标页面 |
| 进入设置 | 用户菜单 | 跳转 `/settings` |
| 退出登录 | 用户菜单 | 清理 Bearer Token 并跳转登录页 |
| 切换主题 | 主题按钮 | 修改 Light / Dark / System 模式 |

**共享约定**
- 所有列表页在主内容区底部使用统一分页器，默认每页 10 条，可切换 `10 / 20 / 50 / 100 / 200`。
- 当全局鉴权相关请求返回 401、403 或 `404 User not found` 时，应用会自动回到登录页而不是停留在错误态。
- 管理员侧边栏当前额外包含 `Accounts`、`API Tokens` 和 `Data Management` 三个系统管理入口。
- 页面标题和主要操作统一使用 `PageHeader`；窄屏下操作自动换到标题下方并可占满容器宽度。
- 统一弹窗最大高度不超过动态视口，内容区可纵向滚动；移动端底部操作按钮采用纵向排列。
- 统一分页器在移动端只保留上一页、当前页信息和下一页，桌面端保留完整页码跳转。
