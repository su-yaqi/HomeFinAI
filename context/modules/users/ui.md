# users 页面详情

## 页面列表
| 页面名 | 路由 | 说明 |
|--------|------|------|
| 用户设置页 | /settings | 当前用户资料、密码与危险操作 |
| 账户管理页 | /system/accounts | 管理员管理系统账户 |
| 兼容管理入口 | /admin | 当前跳转 `/system/accounts` |

## 页面详情

### 用户设置页
- **路由**：`/settings`
- **说明**：维护自己的资料、密码、MFA 状态和危险操作

### 账户管理页
- **路由**：`/system/accounts`
- **说明**：管理员通过分页表格管理用户账户、登录名、角色、状态，并可在操作菜单里执行 `Reset MFA`
- **权限**：管理员

## 移动端行为
- 设置页 Tab 支持横向滚动，资料、密码、MFA 和危险操作区域使用单列布局，主要按钮适配全宽触控。
- 账户管理表格在 `md` 以下切换为账户卡片，展示姓名、登录名、邮箱、角色和状态。
- 账户卡片保留编辑、删除、密码重置与 MFA 重置入口，操作菜单触发器提供至少 44px 触控区域和可访问名称。
