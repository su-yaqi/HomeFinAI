# users 业务流程

## 当前用户设置流程
1. 用户进入 `/settings`。
2. 页面读取当前用户信息。
3. 用户可以修改 `login_name`、邮箱和姓名。
4. 用户可以在独立页签修改密码。
5. 普通用户仍可在危险操作区删除自己的账号。

## 管理员账户管理流程
1. 管理员进入 `/system/accounts`。
2. 页面按统一分页规则读取账户列表。
3. 管理员可新增、编辑、删除账户。
4. 管理员可通过专用接口重置目标账户密码或 MFA Secret。

## 交易经手人候选流程
1. 交易页面初始化时调用 `/users/handler-options`。
2. 后端返回可选用户列表及其展示名。
3. 前端在交易筛选器和编辑表单中复用该候选集。

## 业务规则
- 普通用户只能维护自己的资料和密码。
- 管理员不能删除自己。
- 用户删除时，其关联财务数据和遗留 Item 会随外键级联或显式删除一并清理。
