# api-tokens 页面详情

## 页面列表
| 页面名 | 路由 | 说明 |
|--------|------|------|
| API Token 管理页 | /system/api-tokens | 管理外部 Agent 调用凭证 |

## 页面详情
- **路由**：`/system/api-tokens`
- **说明**：提供分页列表、Token 创建弹窗、一次性明文展示、禁用操作和删除操作
- **权限**：管理员

**移动端行为**
- 桌面表格在 `md` 以下切换为 Token 卡片，展示名称、所属用户、前缀、状态和时间信息。
- Token 前缀、一次性明文 Token 与 Secret 允许断行，并提供显式复制操作。
- 创建、禁用和删除操作在移动卡片和窄屏弹窗中保持可访问。
