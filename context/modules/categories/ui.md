# categories 页面详情

## 页面列表
| 页面名 | 路由 | 说明 |
|--------|------|------|
| 分类管理页 | /system/categories | 管理当前用户分类树 |

## 页面详情
- **路由**：`/system/categories`
- **说明**：通过分页表格与弹窗维护分类名称、颜色和父分类
- **权限**：所有已登录用户

**页面结构**
- 顶部操作区 + 分类表格 + 统一分页器 + 新增/编辑弹窗

**核心交互**
- 颜色字段同时提供浏览器原生颜色选择器和十六进制输入框。
- 切换筛选条件或每页条数后，列表回到第 1 页重新请求。
