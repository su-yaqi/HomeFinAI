# data-jobs 页面详情

## 页面列表
| 页面名 | 路由 | 说明 |
|--------|------|------|
| 数据管理页 | /system/data-management | 管理员执行 Excel 模板下载、导入、导出和任务结果下载 |

## 页面详情
- **路由**：`/system/data-management`
- **说明**：提供“Backup Export”和“Import”两个操作卡片，并展示最近任务列表
- **权限**：管理员

**页面结构**
- 顶部标题与刷新按钮
- 当前运行任务提示区
- 导出卡片
- 导入卡片
- 最近任务表格与分页器

**核心交互**
- 导出按钮创建后台任务，而不是同步下载整表。
- 模板下载直接返回 `.xlsx` 文件。
- 导入先选择 `.xlsx` 文件，再创建后台任务。
- 模板说明和导出结果中的交易字段当前使用 `summary`、`detail_note`、`detail_items`，不要求管理员直接维护 JSON。
- 任务列表在存在 `PENDING` 或 `PROCESSING` 任务时自动轮询刷新。
- 已完成任务可下载结果文件或错误明细文件。
