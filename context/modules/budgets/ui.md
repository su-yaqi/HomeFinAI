# budgets 页面详情

## 页面列表
| 页面名 | 路由 | 说明 |
|--------|------|------|
| 预算管理页 | /budgets | 管理预算与查看已使用金额 |

## 页面详情
- **路由**：`/budgets`
- **说明**：通过分页列表和弹窗维护预算名称、年份、周期与金额
- **权限**：所有已登录用户

**页面结构**
- 顶部操作区 + 预算表格 + 统一分页器 + 新增/编辑弹窗

**移动端行为**
- 桌面表格在 `md` 以下切换为预算卡片，展示名称、周期、金额、已使用金额和剩余金额。
- 新增预算按钮在窄屏下占满可用宽度，卡片内编辑与删除操作保留完整触控区域。
- 新增/编辑弹窗使用单列表单与可滚动内容区。
