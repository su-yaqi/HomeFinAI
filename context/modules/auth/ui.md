# auth 页面详情

## 页面列表
| 页面名 | 路由 | 说明 |
|--------|------|------|
| 登录页 | /login | Bearer 登录入口 |
| 找回密码页 | /recover-password | 发起密码找回 |
| 重置密码页 | /reset-password | 输入新密码完成重置 |
| 兼容注册入口 | /signup | 当前直接跳转 `/login` |

## 页面详情

### 登录页
- **路由**：`/login`
- **说明**：使用 `login_name + password + 可选 MFA Code` 登录
- **权限**：匿名可访问

**核心交互**
| 操作 | 行为描述 |
|------|---------|
| 登录 | 调用 Bearer 登录接口，成功后跳转首页 |
| 输入 MFA | 当用户配置 MFA 时需输入 6 位验证码 |

### 找回密码页
- **路由**：`/recover-password`
- **说明**：输入邮箱后触发找回密码邮件发送

### 重置密码页
- **路由**：`/reset-password?token=...`
- **说明**：通过邮件 token 设置新密码

## 移动端行为
- 登录、找回密码与重置密码页面在 320px 视口下保留安全边距，表单宽度不超出屏幕。
- Logo、主题切换、表单和 Footer 使用单列布局，并兼容设备底部安全区。
- 输入框和主要提交按钮保持完整可触控宽度，密码显示切换不会造成横向溢出。
