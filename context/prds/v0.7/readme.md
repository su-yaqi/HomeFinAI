# v0.7 PRD

## 版本说明
- 版本：v0.7
- 状态：已完成
- 创建时间：2026-07-18

## 本版本目标
让 HomeFin 现有全部终端用户页面在手机端具备清晰、完整且可触控的浏览与操作体验，同时保持桌面端现有功能和信息密度不退化。

## 版本范围
- 覆盖 320px 及以上视口，重点验收 390×844 的主流手机尺寸。
- 覆盖认证、应用框架、财务管理、用户设置和管理员页面。
- 保留现有路由、权限、接口和数据模型，不新增原生 App、PWA 或离线能力。

## 文件组织
| 文件 | 说明 |
|------|------|
| `mobile-experience-foundation.md` | 建立全局移动端布局、公共交互组件与响应式验证基线 |
| `mobile-finance-workflows.md` | 支持用户在手机端完成财务看板、交易、预算和分类操作 |
| `mobile-account-and-administration.md` | 支持用户和管理员在手机端完成账户、安全、Token 与数据任务管理 |

## 实施顺序
1. 先完成 `mobile-experience-foundation.md`，提供后续页面复用的响应式基础。
2. 再并行或依次完成两个业务子需求。
3. 最后执行完整桌面端与移动端回归验收。
