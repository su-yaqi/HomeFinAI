# v0.1 变更记录

## 基本信息
- **完成时间**：2026-05-28
- **对应 PRD**：`context/prds/v0.1/`
- **版本定位**：模板基线版本

## 实现内容

### app-shell
- 提供登录后统一侧边栏布局、顶部栏、页脚与主题切换能力。
- 支持 Light / Dark / System 模式切换与本地持久化。
- 基于路由守卫完成受保护页面访问控制。

### auth
- 完成邮箱密码登录与 JWT 鉴权。
- 完成开放注册流程。
- 完成密码找回、邮件发送与基于 token 的密码重置流程。
- 提供 token 测试接口与本地私有测试用户创建能力。

### users
- 完成当前用户资料查看与编辑。
- 完成当前用户密码修改。
- 完成普通用户删除自己账号的能力。
- 完成管理员用户列表、创建、编辑、删除能力。

### items
- 完成 Item 列表、创建、编辑、删除能力。
- 普通用户仅能管理自己的 Item；管理员可查看全部 Item。
- 页面包含空状态展示。

### engineering
- 接入 OpenAPI 前端 client 生成。
- 提供后端 Pytest、覆盖率统计和前端 Playwright E2E 测试。
- 提供 Docker Compose 本地联调与 GitHub Actions CI 流程。

## PRD 一致性校验结果
当前 `v0.1` 更接近模板基线版本而非严格按 PRD 驱动交付，已将当前实现状态回写到 `context/` 文档中，供后续迭代作为基准。

| PRD 要求 | 实际实现 | 偏差原因 | 处理决策 |
|---------|---------|---------|---------|
| `prds/v0.1` 仍为占位模板 | 当前代码已具备完整模板基线能力 | `context` 初始模板未随代码同步刷新 | 已按当前实现刷新根文档与模块文档 |

## 遗留问题
- `context/prds/v0.1/` 仍保留模板化结构，后续具体业务迭代应新建正式 PRD 内容。
- 前端与后端仍保留模板默认命名 `Item`，后续进入真实业务领域时需要按领域对象重命名。
