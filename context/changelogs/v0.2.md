# v0.2 变更记录

## 基本信息
- **完成时间**：2026-05-29
- **对应 PRD**：`context/prds/v0.2/`
- **版本定位**：HomeFin 业务化落地版本

## 实现内容

### auth
- 用户模型新增 `login_name` 和 `mfa_secret`。
- 登录主路径保持 `POST /login/access-token + Bearer Token`。
- 登录页改为 `login_name + password + 可选 mfa_code`。
- 保留 `POST /login` 和 `POST /logout` 兼容 Session API，但前端主流程未切换到该模式。

### users
- 管理员账户管理路径迁移到 `/system/accounts`。
- 当前用户资料支持维护 `login_name`、`email`、`full_name`。
- 新增管理员重置密码与重置 MFA Secret 接口。
- `UserPublic` 增加 `has_mfa` 字段。

### finance-core
- 新增分类管理、预算管理、交易管理三组核心后端接口和前端页面。
- 交易支持按日期、类型、分类、入账状态、经手人筛选。
- 交易支持批量标记为 `ENTERED`。
- 金额在 API 层使用元，在数据库层统一存储为分。

### dashboard
- 首页从模板欢迎页切换为财务 Dashboard。
- 提供本月收支汇总、最近 6 个月趋势、分类支出占比和预算使用情况。

### external-access
- 新增管理员 API Token 管理页与后端接口。
- Token 支持过期时间、禁用、一次性明文返回和可选 HMAC Secret。
- 新增 `/agent/transactions` Agent 交易接口，支持 Bearer Token 或 `X-API-Token` 认证，并在成功调用后更新 `last_used_at`。
- 新增 `/agent/budgets` Agent 预算接口，支持预算列表、创建、更新、删除，并返回 `used_amount` 聚合值。
- 新增 `/agent/categories` Agent 分类接口，支持分类列表、创建、更新、删除，并复用父分类、颜色与删除前依赖校验规则。

### compatibility
- 旧 `/items` 前端路由改为跳转 `/transactions`。
- 旧 `/admin` 前端路由改为跳转 `/system/accounts`。
- 后端 `items` API 和 `/users/signup` 兼容接口仍保留。

### verification
- 后端认证与财务域回归测试通过：`45 passed`
- 前端 `npm run build` 通过
- 前端 `npm run lint` 通过

## 设计决策回写
| 设计点 | 最终决策 |
|--------|---------|
| 认证主路径 | 保留 Bearer Token，不强制迁移到 Cookie Session |
| 公共注册 | 前端入口移除，后端接口兼容保留 |
| 财务域前端 API | 当前先使用手写 `homefinApi` 封装，未完全并入生成客户端 |
| 遗留 Item | API 保留，主业务路径迁移到 Transaction |
