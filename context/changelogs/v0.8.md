# v0.8 变更记录

## 基本信息
- **完成时间**：2026-07-29
- **对应 PRD**：无独立 PRD；来源于安全与数据完整性收口审查
- **版本定位**：认证、Agent 调用与数据库完整性加固版本

## 实现内容

### auth-session-hardening
- Bearer、Cookie Session 与密码重置 Token 增加独立用途类型，不能跨用途复用。
- 用户新增 `auth_version`；当前用户修改密码、找回密码成功或管理员重置密码后，旧登录态和旧重置 Token 全部失效。
- 密码重置 Token 绑定签发时的认证版本，成功使用后不能再次使用。

### agent-hmac-replay-protection
- 带 HMAC Secret 的 Agent Token 现在必须在每次请求携带 Secret、Unix 时间戳、随机 Nonce 和签名。
- 时间戳只接受服务端前后 5 分钟窗口，Nonce 长度限制为 16 至 128 个字符。
- 新增 `apitokennonce` 表和 `(token_id, nonce)` 唯一约束，并拒绝已接受过的重放请求。

### category-and-account-integrity
- 分类名称增加 `(owner_id, name)` 数据库唯一约束，颜色增加十六进制格式 Check Constraint。
- 应用层拒绝分类自引用和任意深度的父子环。
- 迁移会合并既有重复分类、重定向交易引用、断开既有分类环，并把非法颜色归一化为 `#64748b`。
- API Token 的创建人外键改为级联删除；账户删除时同步清理其 Token 和 HMAC Nonce。

## 迁移与回退边界
- 结构降级可以撤销 `auth_version`、`apitokennonce`、分类约束和 API Token 级联外键。
- 升级阶段已合并的重复分类、已断开的分类环和已归一化的颜色不会在降级时自动恢复。
- 正式环境执行迁移前必须完成数据库备份；迁移失败时应停止并报告，不能把结构降级等同于数据自动回滚。

## 设计决策回写
| 设计点 | 最终决策 |
|--------|---------|
| 登录态撤销 | 通过用户级 `auth_version` 同时撤销 Bearer、Session 和密码重置 Token |
| Token 用途隔离 | Token 必须携带并匹配 `typ`，不同用途不可互换 |
| HMAC 防重放 | 使用 5 分钟时间窗口和数据库唯一 Nonce，不能回退为仅 Token 调用 |
| 分类完整性 | 应用层校验层级，数据库约束兜底名称并发唯一与颜色格式 |
| 迁移回退 | Schema 可降级，数据清洗不可逆，正式迁移依赖事前备份 |
