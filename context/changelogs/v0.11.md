# v0.11 变更记录

## 基本信息

- **完成时间**：2026-07-30
- **对应 PRD**：无独立 PRD；来源于开发环境与工程流程分阶段改造 Phase 3
- **版本定位**：风险分级 CI、单一 required gate 与测试基线恢复

## 实现内容

### risk-based-ci

- 新增统一 `CI` 工作流，覆盖 PR、`main`、夜间和手动完整运行。
- 新增 `scripts/ci-plan.sh`，按路径推断最低 S/M/H 风险并选择后端、前端、E2E、
  Compose 与制品校验；H 和非 PR 完整运行不能缩减。
- 新增 `make test-ci-plan` 回归 S 文档、M 前后端、H 安全路径与完整运行选择。
- 原有独立后端、Playwright、Compose 和 pre-commit 工作流改为手动诊断入口，取消
  PR/main 重复触发与 pre-commit 自动提交推送。

### single-gate

- 建立稳定门禁 `CI / CI Required`，统一汇总所有本次被选择的作业。
- 纯 S 文档变更允许跳过无关后端、前端、E2E、Compose 与制品作业；任何被选择作业
  失败都会使门禁失败。

### artifact-validation

- 新增 `make validate-compose`，渲染开发与内网 Compose，并验证内网 `8000/8080/8081`
  访问语义、`db-backup`、`app-db-backups` 和每日备份计划。
- CI 校验冻结的 Python/Bun 锁文件、生成客户端无漂移、Alembic 迁移头、前端正式
  构建和 Compose 冒烟。
- 客户端生成脚本可在没有部署 `.env` 的干净 CI 检出中使用仅用于 schema 生成的安全
  默认值，且不再开启 Shell 命令回显。

### test-baseline

- 将过期的邮箱登录、公开注册、Users/Items 用例更新为当前登录名、Accounts、
  Transactions 和禁用公开注册语义，同时保留旧路由重定向验证。
- 补充 Cookie/CSRF 登录退出、无效/停用/MFA 登录、密码恢复，以及预算和分类 CRUD、
  分页和完整性错误路径测试。

## verification

- 后端完整套件：109 项通过，覆盖率 90%（门槛未降低）。
- 完整 Playwright：77 项通过，覆盖桌面、移动 Chrome 和移动 Safari。
- 前端 Biome 检查通过；TypeScript 与 Vite 正式构建通过。
- S/M/H CI 计划脚本回归、开发流程规则回归、开发/内网 Compose 渲染和备份配置校验
  通过。
- GitHub Actions YAML 与 Zizmor 工作流安全检查通过。

## 设计决策回写

| 设计点 | 最终决策 |
| --- | --- |
| PR 选择 | 路径给最低风险；H 无条件完整，S 可跳过无关 E2E |
| 默认分支 | `main`、夜间和手动运行始终全量 |
| Required check | 只要求 `CI / CI Required` |
| 旧工作流 | 保留手动诊断，不再重复触发或自动修改分支 |
| 覆盖率 | 补真实分支测试，保持 90% 门槛 |
