# v0.13 变更记录

## 基本信息

- **完成时间**：2026-08-18
- **对应 PRD**：[`../prds/v0.13/readme.md`](../prds/v0.13/readme.md)
- **版本定位**：以原生 MCP/OAuth AI Connector 替代旧 Agent API、手工 API Token 和专用 Skill

## 实现内容

### MCP 与 OAuth 连接

- 提供 MCP Server Discovery、工具发现与工具调用入口，使用 OAuth Authorization Code、PKCE、
  CIMD 客户端身份、短期 Access Token 和可轮换 Refresh Token。
- 新增 AI 连接授权页和用户设置中的连接管理，支持连接状态、最后使用时间和撤销。
- 提供财务洞察、交易、预算和分类工具；写工具使用两阶段确认、请求摘要、幂等键和连接级权限边界。
- 新增连接、授权码、授权决定、刷新令牌和幂等操作数据模型及迁移。

### 旧 AI 接入链路退役

- 删除 Agent REST API、管理员 API Token 管理接口与页面，以及 `homefin-agent-api` Skill。
- 保留历史 `apitoken` 表作为升级影响审计边界；迁移停用活动 Token，启动前审计近期使用情况，
  存在受影响集成时要求部署者精确确认后才允许继续。
- 前后端生成客户端、导航、测试和 context 文档统一切换到 AI Connector 定位，不保留同定位双入口。

### 分支与依赖收口

- 合并本地多实例开发环境、风险分级 CI、不可变镜像晋级和安全发布链路。
- 合并 Python、GitHub Actions、Playwright 和前端依赖更新；FastAPI 升级到 `0.138.0`，
  Playwright 包与容器统一为 `1.62.1`。
- 完成 Vite 8 和 Biome 2.5 配置迁移；`@hey-api/openapi-ts 0.73.0` 尚不支持 TypeScript 7，
  因此保持已验证的 TypeScript 5.9。TanStack Table 9 会替换现有核心 API，同样保持已验证的 v8 系列，
  等待独立迁移任务处理。
- 修复 CI 生成客户端的 OpenAPI 二进制上传表示和跨平台空行归一化、后端测试错误依赖宿主机数据库端口，
  以及 Compose 启动后探活过早问题；
  后端 CI 统一复用隔离的 `make test-backend` 标准入口。

## 回滚与外部完成边界

- 发布前必须执行旧 AI 接入影响审计和 PostgreSQL 备份；应用健康失败时按发布脚本恢复上一组不可变镜像，
  不自动执行 schema downgrade。
- 当前 GitHub 仓库尚未配置 `staging` Environment，也没有可确认的 `self-hosted + staging` Runner；
  因此真实 staging 部署和健康检查证据仍不存在。v0.13 在完成该外部配置和 staging 验证前保持未发布状态，
  不得把本地迁移演练或浏览器测试描述为 staging 通过。
