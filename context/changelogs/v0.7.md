# v0.7 变更记录

## 基本信息
- **完成时间**：2026-07-18
- **对应 PRD**：`context/prds/v0.7/`
- **版本定位**：全站移动端体验与响应式基线版本

## 实现内容

### mobile-experience-foundation
- 已登录应用框架新增移动顶部栏、44px 菜单触发器、抽屉侧边栏与窄屏内容边距，桌面常驻侧栏保持不变。
- 新增统一 `PageHeader`，页面标题、说明和主要操作可根据宽度自动换行。
- 通用 `Dialog` 限制在动态视口内并支持内容滚动，移动端底部按钮改为纵向全宽布局。
- `TablePagination` 在移动端提供上一页、当前页与下一页的紧凑模式，桌面端继续显示完整页码。
- `DataTable` 支持复用同一数据源分别渲染桌面表格和移动卡片。
- 认证布局、Footer、页面根容器与长文本均补充移动安全边距和溢出保护。

### mobile-finance-workflows
- Dashboard 的标题、摘要、图表和金额信息在窄屏下按单列与可换行方式展示。
- 交易页新增移动端折叠筛选器、启用条件计数、交易卡片、当前页选择器和固定批量操作栏。
- 预算与分类列表在移动端使用卡片视图，保留新增、编辑、删除、分页和全部字段信息。
- 交易、预算和分类的新增/编辑弹窗均支持 320px 视口内滚动与触控操作。

### mobile-account-and-administration
- 设置页 Tab 支持横向浏览，资料、密码和 MFA 操作在窄屏下改为单列或全宽按钮。
- 账户、API Token 与数据任务列表新增移动卡片视图，并保留管理员全部操作。
- 账户操作菜单扩大触控区域并补充可访问名称。
- 一次性 Token 与 Secret 新增复制操作和长文本断行，避免泄漏到页面横向区域之外。
- 数据导入导出卡片、文件选择和任务操作适配单列移动布局。

## verification
- 前端生产构建通过：`npm run build`。
- Biome 检查通过：本轮变更的前端源文件与测试文件无格式或静态检查错误。
- 品牌静态测试通过：`node --test tests/branding-static.test.mjs`。
- 移动端 Playwright 回归通过：Pixel 5 Chromium 与 iPhone 12 WebKit 共 25 项，覆盖全部现行页面、320px 视口、认证页、移动侧栏和长交易弹窗。
- 桌面端响应式冒烟回归通过：Desktop Chrome 共 10 项，覆盖全部现行受保护页面、桌面侧栏和交易弹窗。
- 既有桌面全量套件仍包含 `/items`、`/signup`、旧 `/admin` 和旧邮箱登录字段等历史用例；这些用例与当前路由和登录模型不一致，不计入 v0.7 验收通过项，后续应独立清理测试基线。

## 设计决策回写
| 设计点 | 最终决策 |
|--------|---------|
| 响应式范围 | 支持 320px 及以上视口，重点验证 390×844 主流手机尺寸 |
| 列表策略 | `md` 以下使用移动卡片，桌面端保留现有表格与信息密度 |
| 导航策略 | 移动端使用抽屉侧边栏，桌面端继续使用常驻侧栏 |
| 筛选策略 | 交易筛选在移动端默认折叠并显示已启用条件数量 |
| 批量操作 | 保留当前页选择语义，移动端批量操作栏固定在可见区域底部 |
| 弹窗策略 | 不改业务表单和提交语义，只增加动态视口约束、内容滚动和移动按钮布局 |
| 兼容边界 | 不修改路由、权限、API 和数据模型；桌面端不降低现有信息密度 |
