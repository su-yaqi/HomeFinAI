# v0.4 变更记录

## 基本信息
- **完成时间**：2026-06-01
- **对应 PRD**：`context/prds/v0.4/`
- **版本定位**：系统级数据导入导出与大体量处理支撑版本

## 实现内容

### data-management-ui
- 新增管理员页面 `/system/data-management`。
- 页面提供“Backup Export”和“Import”两块功能区域。
- 支持模板下载、Excel 上传、导出任务创建、任务列表轮询、结果文件下载和错误明细下载。
- 管理员侧边栏新增 `Data Management` 入口。

### data-jobs-api
- 新增 `/api/v1/system/data-jobs/` 分页任务列表接口。
- 新增 `/api/v1/system/data-jobs/export` 与 `/api/v1/system/data-jobs/import`。
- 新增 `/api/v1/system/data-jobs/template`、`/{job_id}/result`、`/{job_id}/errors` 下载接口。
- 全部接口仅管理员可访问。

### excel-import-export
- 系统统一使用多页签 `.xlsx` 作为导入导出格式。
- 当前模板和导出结果固定包含 `README`、`Categories`、`Budgets`、`Transactions` 四个页签。
- 导入采用 `owner_login_name` 作为归属用户定位字段，可面向全系统账户批量处理分类、预算和账单数据。

### bulk-processing
- 新增 `datajob` 与 `datajoberror` 持久化导入导出任务和行级错误。
- 后端通过 `BackgroundTasks` 执行导入导出，避免长耗时请求阻塞前端。
- 账单导出按批次读取，账单导入按批次写入。
- 行级错误写入错误表，并可额外导出为错误明细工作簿。

## 设计决策回写
| 设计点 | 最终决策 |
|--------|---------|
| 导入导出格式 | 首版只支持多页签 `.xlsx` |
| 异步执行策略 | 使用 FastAPI `BackgroundTasks` + `datajob` 表，而不是额外引入消息队列 |
| 任务结果存储 | 结果文件和错误文件当前落在本地临时目录 |
| 系统管理权限 | `/system/data-management` 和相关接口仅管理员可访问 |
| 大体量处理 | 交易数据采用分批读取/写入，避免一次性全量装载 |
