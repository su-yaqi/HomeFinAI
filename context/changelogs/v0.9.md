# v0.9 变更记录

## 基本信息
- **完成时间**：2026-07-29
- **对应 PRD**：无独立 PRD；来源于开发环境与工程流程分阶段改造 Phase 1
- **版本定位**：本地多项目、多 worktree 和多实例环境隔离

## 实现内容

### deterministic-instance-contract
- 新增根目录 `Makefile` 与 `scripts/dev.sh` 统一入口。
- 默认 Compose project 为 `homefin-dev-${DEV_SLOT}`；每个 slot 从
  `DEV_PORT_BASE=21000` 起按 20 个端口确定性分块。
- 同一 project 派生独立的前后端镜像标签，避免不同 worktree 共用本地应用镜像。
- 启动成功后显示 Frontend、Backend、API 文档和全部按需工具的稳定地址。

### conflict-and-ownership-guard
- 启动前检查同名 Compose project 的容器和保留卷 worktree 归属；实例停止后，
  其他 worktree 也不能静默接管同一 slot 的数据卷。
- 检查当前 slot 的宿主机入口端口；冲突信息包含 Docker project/service 或宿主机
  监听进程。
- 冲突时直接失败，不自动停止、删除或重建其他项目的容器。

### minimal-default-exposure
- 默认仅将 Frontend 和 Backend 绑定到 `127.0.0.1`。
- PostgreSQL 保持 Compose 内网访问，不再默认暴露宿主机端口。
- Adminer、Mailcatcher UI/SMTP 和 Playwright UI 改为按需 profile，并分配当前
  slot 内的确定性端口。

### isolated-test-projects
- Backend 与 Playwright 测试分别使用
  `${DEV_PROJECT}-dev-${DEV_SLOT}-test-backend` 和
  `${DEV_PROJECT}-dev-${DEV_SLOT}-test-e2e`。
- 测试覆盖文件移除前后端宿主机端口，并在结束时仅清理当前测试 project 的容器、
  网络和卷。
- Playwright 容器内浏览器固定使用 `http://localhost:5173`，Backend 的 CORS
  同步使用该内部测试源，避免错误继承宿主机 slot 地址。

### production-boundary
- `compose.intranet.yml` 未修改。
- 内网正式部署仍显式使用 `compose.yml + compose.intranet.yml`，不继承 slot、
  本地端口范围或开发工具 profile。

## 设计决策回写
| 设计点 | 最终决策 |
|--------|---------|
| 端口分配 | 固定基址 + slot × 20，不采用随机端口 |
| 项目隔离 | 稳定 project 名并校验 worktree 归属，不复用默认目录名 |
| 冲突处理 | 报告占用者并失败，不停止其他项目 |
| 默认暴露 | 仅 Frontend/Backend 绑定回环地址，管理与测试工具按需 |
| 测试清理 | 只清理精确派生的测试 project，清理失败显式报错 |
| 正式部署 | 本地开发覆盖与 `compose.intranet.yml` 保持独立 |
